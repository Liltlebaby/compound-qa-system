# ทางเข้าจากในและนอกโรงงานผ่าน HTTPS

ยังไม่ได้เปิดทางเข้าจากอินเทอร์เน็ตให้คอมอีกเครื่อง เอกสารนี้เตรียมขั้นตอนสำหรับตั้งค่าที่เครื่องเซิร์ฟเวอร์จริง

แนวทางสำหรับใช้งานจริงคือ **โดเมนถาวร + Cloudflare Tunnel → เซิร์ฟเวอร์โรงงานพอร์ต 3000** ข้อมูลหลักยังเก็บใน SQLite บนคอมโรงงาน การเชื่อมต่อของผู้ใช้ผ่านเครือข่าย Cloudflare จึงต้องใช้บัญชี/โดเมนของโรงงานในการตั้งค่า

## ใช้งานจริง

1. เลือกโดเมนถาวรของโรงงานและเชื่อม DNS กับบัญชี Cloudflare ของโรงงาน
2. สร้าง Tunnel และติดตั้ง cloudflared บนคอม Windows ตามคำสั่งที่ Cloudflare ออกให้ บัญชี/โทเคนต้องทำบนเครื่องนั้น ไม่ใส่ลง source หรือส่งในแชต
3. กำหนด public hostname เช่น qa.โดเมนของโรงงาน ให้ชี้บริการ HTTP ที่ http://localhost:3000
4. คง Host ของโดเมนสาธารณะ และส่ง X-Forwarded-Proto=https มายังแอปตามปกติ อย่าตั้ง Host override เป็น localhost
5. ใช้ HTTPS ที่ hostname นี้จากทั้ง Wi-Fi โรงงานและอินเทอร์เน็ตมือถือ ให้ทุกคนใช้ URL เดียวกัน
6. เข้าระบบหัวหน้าบนคอม ตั้ง “ที่อยู่เว็บสำหรับ QR” เป็น https://hostname จริง ไม่มี path ต่อท้าย
7. เข้า QR ประจำจุดของแต่ละโรง ดาวน์โหลด/พิมพ์ใหม่ แล้วทดสอบด้วยกล้องมือถือและบัญชี QA จริง

Tunnel เชื่อมออกจากเครื่องโรงงาน ไม่จำเป็นต้องเปิดพอร์ตเว็บจากเราเตอร์เข้าคอมโดยตรง ตั้ง Tunnel ให้ทำงานเป็น Windows service และให้แอป QA เริ่มอัตโนมัติด้วย scripts/windows/INSTALL-AUTOSTART.ps1

หากใช้งานผ่าน Tunnel อย่างเดียว สามารถตั้ง QA_HOST=127.0.0.1 เพื่อลดการรับการเชื่อมต่อ HTTP โดยตรงใน LAN ทั้งนี้ต้องตั้งค่าก่อนติดตั้งงานเริ่มอัตโนมัติหรือปรับ action ของงานให้ใช้ค่าที่ต้องการ

## ทดลองสั้น ๆ ก่อนมีโดเมน

Cloudflare Quick Tunnel เปิด HTTPS แบบชั่วคราวได้โดยไม่ต้องมีโดเมน ใช้ทดสอบการเปิดจากนอกโรงงานเท่านั้น:

    cloudflared tunnel --url http://localhost:3000

ใช้ URL ที่โปรแกรมแสดง แล้วตั้ง URL ในหน้าหัวหน้าเพื่อทดสอบ QR ห้ามพิมพ์เป็น QR ถาวร เพราะ hostname เปลี่ยนเมื่อสร้าง Quick Tunnel ใหม่

เอกสารนี้ไม่ได้ติดตั้ง cloudflared สร้างบัญชี ซื้อโดเมน หรือเปิด Tunnel ให้โดยอัตโนมัติ

## ตรวจรับก่อนใช้หน้างาน

- มือถือ 2 เครื่องที่อยู่คนละเครือข่ายเปิด HTTPS เดียวกันและใช้บัญชีพนักงานได้
- QR ระบุโรงและจุดถูกต้อง AJ2 เลือกกะ AJ2B เป็นกะเช้า 08:00–19:00
- ข้อมูลของคนละโรง/กะไม่ปะปน และ QA เข้าจุดที่ไม่ได้รับสิทธิ์ไม่ได้
- เปิดเว็บออนไลน์ครั้งแรกแล้วทดลองปิดเน็ต กรอกและส่ง รอส่งต้องยังอยู่ เมื่อเน็ตกลับส่งเพียงหนึ่งครั้ง
- ปิดทุกหน้าเว็บแล้วให้เซิร์ฟเวอร์สร้างรายงานเมื่อครบเวลาและข้อมูลครบ
- คอมและอินเทอร์เน็ตโรงงานต้องเปิดอยู่ หาก Internet ขาดในโหมด Tunnel ให้ใช้แบบร่าง/คิวออฟไลน์จนเชื่อมต่อกลับ
- คิวใน browser แยกตาม origin จึงไม่ควรสลับระหว่าง IP ภายในและโดเมนสาธารณะระหว่างมีข้อมูลรอส่ง
